# キャプションボード作成ツール

Google フォームの回答 CSV から、展示用のキャプションを A4 に敷き詰めて印刷できるページにする Web アプリ。

読み込んだ CSV はブラウザの中だけで処理し、どこにも送らない。1 つの HTML ファイルにまとめた版は、インターネットにつながっていなくても動く。

> 現在は開発の初期段階で、まだ使える状態ではない。
